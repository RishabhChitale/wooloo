The companion's room can be resized: drag the thin strip along its bottom edge (double-click resets), or use the new Size slider in Webcam Settings. A Zoom slider magnifies the whole scene, background and sprite together, around the sprite so she stays put in the room.

The GitHub panel is now hidden by default behind a GitHub toggle next to the Files toggle, in the View menu and in the command palette. With both Files and GitHub hidden, the Spaces list takes the rest of the sidebar's height.
