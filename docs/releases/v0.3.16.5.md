Includes everything planned for 0.3.16.4, which was never released:

> The companion's speech bubble now shows what the commander agent actually said: a sentence from the end (while working or waiting) or the start (done or idle) of its newest Claude Code reply, read from the tail of the session transcript on this Mac and never stored or logged. The companion can also stand in a background scene, with a night variant from 20:00 to 06:00, when the local manifest provides one. Artwork is still loaded from the local companion folder and is not included.

The right sidebar gains an ACTIVE TASKS section under Spaces: jobs registered as JSON files in `~/.local/share/wooloo-companion/tasks` (shown while their process runs, for the selected Space or for none), and queued or running GitHub Actions runs of the Space's repository and of any repositories listed in `~/.local/share/wooloo-companion/ci-repos.txt`, polled with `gh`. Each row shows a spinner, its source, a label and the elapsed time; a CI row opens its run in the browser.
